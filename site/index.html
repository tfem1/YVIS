GraveyardOS

frail.lol/tfem

A Linux distribution built from source, with its own package manager.

Linux From Scratch 13.1 with systemd. Rolling release, prebuilt binaries, for people who like to know what is on their machine.

IN DEVELOPMENT

Works today

  • Base systemEvery package of the book built from source in CI, then checked.
  • Live ISOBoots on BIOS and UEFI, from a disc or a USB stick; from a Ventoy stick on BIOS (UEFI: fixed, in the next ISO).
  • YoneSigned packages, atomic installs, file verification. Written in Rust.

Coming

  • DesktopsKDE Plasma on Wayland, the standard desktop. Hyprland, with its author's dotfiles.
  • AppsFlatpak with Flathub. Firefox, kitty.
  • HardwareNVIDIA open modules. Firmware is the only non-free part.
  • Installerext4, optional encryption, zram.

Yone, in short

sudo yone updateupdate everything: fresh signed indexes, then every package
sudo yone install pkginstall a package and what it needs
sudo yone remove pkgremove a package
yone search wordsearch names and descriptions
yone listevery package the repositories offer, installed ones marked
yone list --installedwhat is installed
yone info pkgdetails of a package
sudo yone autoremoveremove dependencies nothing needs anymore
sudo yone verifycheck every installed file against its checksum
